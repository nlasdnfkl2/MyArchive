# MY-ARCHIVE 95 OS — 기능 확장 및 고도화 개발 계획서 (v2.0 Roadmap)

> **Windows 95 + Neo-Brutalism 데스크톱 환경과 Google Apps Script 서버리스 아키텍처에 바이브코딩 핵심 실습 모듈(데이터 영속성·시각화·게이미피케이션·AI OCR·소셜 공유)을 결합한 차세대 확장 계획서**

---

## 1. 기획 배경 및 강의 핵심 원리 반영 전략

## 2. 신규 기능 및 내장 앱(`.EXE`) 상세 명세 (PRD 기반)

### 2.1 하이브리드 로컬 캐싱(`LocalStorage`) 및 모바일 반응형 PWA 셸
* **해결할 문제:** 구글 시트(`GAS`) 초기 통신 시 로딩 대기 시간이 발생하며, 스마트폰 브라우저에서 다중 창 드래그 UI 조작이 불편함.
* **핵심 기능:**
  * **오프라인 우선(Offline-First) 캐싱 (`config.js`, `archive-app.js`):** 앱 부팅 시 `LocalStorage`에 캐싱된 최근 아카이브·메모 데이터를 0.1초 만에 우선 렌더링한 뒤, 백그라운드에서 GAS 시트와 최신 데이터를 동기화합니다. (브라우저 5MB 용량 한도를 고려하여 Base64 원본 이미지 대신 텍스트 메타데이터와 URL만 캐싱)
  * **반응형 OS 레이아웃 (`style.css`):** 화면 폭 `768px` 이하 모바일 기기에서는 가로 스크롤 없이 단일 창 전체 화면 모드 및 하단 고정 시작 메뉴 바 형태로 자동 전환됩니다.
  * **PWA 홈 화면 추가 (`manifest.json`):** 스마트폰 브라우저의 '홈 화면에 추가 / 앱으로 설치'를 지원하여 네이티브 앱처럼 독립 실행합니다.

### 2.2 감상 일정 달력 및 D-Day 트래커 (`CALENDAR95.EXE`)
* **해결할 문제:** 카드 그리드만으로는 월별 감상 빈도의 흐름이나 예정된 개봉일·공연일·완독 목표일을 한눈에 파악하기 어려움.
* **핵심 기능:**
  * **월별 Win95 캘린더 그리드:** `watchDate`를 기준으로 해당 날짜 칸에 작품 표지 썸네일이나 매체 스티커(도서/음악/영상)를 표시하고, 날짜 클릭 시 당일 감상 목록 팝업을 띄웁니다.
  * **문화생활 D-Day 카운터:** 기대작 개봉일, 콘서트 일정, 도서 반납일 등을 등록하면 남은 일수(`D-Day`)순으로 자동 정렬·하이라이트합니다.

### 2.3 고도화 데이터 시각화: 인터랙티브 연표 & 레이더 비교 차트
* **해결할 문제:** 기존 도넛/막대 차트는 전체 누적량만 보여주어 시기별 취향 변화나 상·하반기 감상 패턴 비교가 어려움.
* **핵심 기능:**
  * **`TIMELINE95.EXE` (가로 스크롤 감상 연표):** 감상 일자 순으로 노드가 배치되는 가로 타임라인을 제공하며, 동일 월에 여러 작품이 있을 경우 클러스터 배지로 묶어 표시하고 노드 클릭 시 상세 탐색기 창을 실행합니다.
  * **기간별 취향 비교 레이더 차트 (`visualizer.js`):** 상반기(파란색)와 하반기(빨간색)의 매체·장르별 감상 비중 및 평균 평점을 다각형 레이더 차트 위에 겹쳐 렌더링하고, **차트 PNG 저장** 및 **자동 취향 편중도 진단 요약 텍스트**(연속 기록 일수 Streak, 최다 집중 장르 분석)를 출력합니다.

### 2.4 감정 기반 큐레이션 & 내 아카이브 복습 퀴즈
* **해결할 문제:** 기록이 수십 건 이상 쌓이면 과거에 감명 깊게 본 작품과 한줄평을 다시 꺼내 보기 어려움.
* **핵심 기능:**
  * **`MOODPICK.EXE` (감정 상태별 아카이브 랜덤 추천기):** `[기쁘고 행복함]`, `[슬프고 우울함]`, `[지치고 번아웃]`, `[불안하고 스트레스]` 감정 버튼을 누르면 해당 분위기의 장르·한줄평을 가진 내 아카이브 작품을 무작위로 추천합니다. (직전에 추천된 작품이 연속 출현하지 않도록 중복 방지 큐 적용)
  * **`QUIZ95.EXE` (`GAMEPACK95.EXE` 확장):** 내 `Archive` 시트 데이터를 문제 은행으로 삼아 **"이 한줄평을 남긴 작품은?"**, **"이 작품의 제작자/아티스트는?"** 4지선다 퀴즈 및 최대 2회 제공되는 **초성 힌트 미니게임**을 생성합니다. 정답 시 8비트 팡파르 효과음과 폭죽 파티클을 연출합니다.

### 2.5 AI 표지·티켓 자동 인식(OCR) 및 문화생활 가계부 (`BUDGET95.EXE`)
* **해결할 문제:** 도서 구매 영수증, 영화 티켓, 음반 커버 정보를 수동 입력하는 번거로움이 있으며, 월간 문화생활 지출 규모를 통제하기 어려움.
* **핵심 기능:**
  * **이미지 기반 자동 메타데이터 추출:** 새 기록 등록 창(`win-register`)에 책 표지나 영수증·티켓 이미지를 업로드하면 Vision AI 또는 OCR 파서를 통해 작품명, 날짜(`YYYY-MM-DD`), 결제 금액(천 단위 쉼표 정규화)을 자동 추출해 입력 폼에 채워줍니다. (인식 실패 시 수동 입력 폴백 안내 및 `1MB` 이하 클라이언트 이미지 압축 처리)
  * **`BUDGET95.EXE` (문화생활 예산 관리 & 소비 회고 영수증):** 기록 등록 시 선택 입력하는 `비용(price)` 데이터를 집계하여 월별 문화 예산 한도를 설정하고, 예산 초과 시 경고 알림 락(Lock)을 제공합니다. 또한 작품을 구매·감상한 이유를 정리해 **Win95 감열지 스타일 영수증**으로 출력(브라우저 인쇄/PDF 저장)할 수 있습니다.

### 2.6 감상 완료 커스텀 디지털 도장 생성기 (`STAMP95.EXE`)
* **해결할 문제:** 완독한 책이나 감상을 마친 작품 카드에 나만의 인증 표식을 남기고 싶음.
* **핵심 기능:**
  * 도장에 새길 문구(예: `완독 인증`, `인생 영화`, 사용자 이름 3글자), 서체(명조, 고딕, 손글씨체), 외곽선 형태(원형, 사각형), 인주 색상을 선택하여 **투명 배경 PNG 도장 파일**을 다운로드하거나, 상세 탐색기 창에 인증 스탬프로 부착합니다.

### 2.7 공유용 QR 코드, 방문자 추천 우체통 & 이메일 알림 (`GUESTBOX.EXE`)
* **해결할 문제:** GitHub Pages로 아카이브를 공개했을 때 방문자가 작품을 추천하거나 감상평을 남길 소통 창구가 없음.
* **핵심 기능:**
  * **원클릭 접속 QR 코드 모달:** 현재 배포된 GitHub Pages URL을 즉시 QR 코드로 생성하여 스마트폰 스캔이나 지인 공유를 지원합니다.
  * **방문자 작품 추천 우체통 & 작품별 방명록:** 방문자가 익명 또는 닉네임으로 추천 작품이나 감상 댓글을 남기면 구글 시트(`Guestbook` 시트)에 자동 기록됩니다.
  * **교사/관리자 이메일 즉시 알림 (`Code.gs`):** 새 추천이나 우체통 메시지가 `doPost`로 접수되면 Google Apps Script의 `MailApp` / `GmailApp`을 호출해 관리자 이메일로 즉시 알림을 발송합니다. (관리자 비밀번호 인증 기반 삭제/승인 관리 지원)

## 4. 바이브코딩 4단계 전략 기반 실행 로드맵

강의에서 제시한 **① 뼈대 → ② 기능 → ③ 디자인 → ④ 점검**의 짧은 반복 사이클을 적용하여 기존 코드의 안정성을 해치지 않고 단계별로 구현합니다.

### Phase 1: 데이터 영속성 및 모바일 접근성 확보 (1주차 목표)
1. **뼈대:** `manifest.json` 생성 및 `index.html`에 반응형 뷰포트·모바일 하단 태스크바 구조 설계.
2. **기능:** `LocalStorage` 캐싱 동기화 로직(`config.js`) 및 접속 QR 코드 생성 모달 구현.
3. **디자인:** `768px` 이하 모바일 화면에서 단일 창 전체 화면 전환 및 터치 영역 최적화(`style.css`).
4. **점검:** 오프라인 상태에서 새로고침 시 데이터 유지 여부 및 스마트폰 브라우저 가로 스크롤 유무 검증.

### Phase 2: 탐색·시각화·게이미피케이션 고도화 (2주차 목표)
1. **뼈대:** `CALENDAR95.EXE`, `TIMELINE95.EXE`, `MOODPICK.EXE` 창 컨테이너 및 메뉴바 연결.
2. **기능:** 월별 달력 렌더링, 가로 타임라인 노드 맵, 감정별 비연속 랜덤 추천, 아카이브 기반 `QUIZ95.EXE` 로직 구현.
3. **디자인:** `visualizer.js`에 상·하반기 비교 레이더 차트 및 PNG 저장 버튼 추가, 8비트 효과음 연동.
4. **점검:** 필터 변경 시 달력·차트·퀴즈 문제 은행의 수치 일치 여부 및 동일 항목 연속 출현 방지 테스트.

### Phase 3: AI OCR 입력 자동화·가계부·소셜 우체통 연동 (3주차 목표)
1. **뼈대:** `Archive` 시트 열(`비용`, `감정태그`) 확장 및 `Guestbook` 시트 자동 생성 로직(`Code.gs`) 추가.
