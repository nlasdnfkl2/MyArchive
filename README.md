# MY-ARCHIVE 95 OS

> Windows 95 + Neo-Brutalism 데스크톱과 Google Apps Script 백엔드를 결합한 개인 문화·예술 감상 기록 웹 OS

도서, 음악, 영화·시리즈, 웹 콘텐츠를 기록하고 내장 앱으로 탐색·재생·통계·공유까지 한 환경에서 처리하는 웹 워크스테이션입니다.

- **배포:** <https://nlasdnfkl2.github.io/MyArchive/>
