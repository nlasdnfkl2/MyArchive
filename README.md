# MY-ARCHIVE 95 OS

> **Windows 95 + Neo-Brutalism 데스크톱 환경 기반의 개인 문화 감상 아카이빙 및 취향 데이터 노드 OS**

별도의 유료 서버나 데이터베이스 구축 없이 **Google Sheets와 Google Apps Script(GAS)**를 서버리스 백엔드로 활용하여 도서·음악·영상 등 감상 기록의 영구 저장(CRUD), 다중 소스 메타데이터 자동 수집, YouTube 백그라운드 주크박스 재생, 선택형 데이터 노드 시각화를 제공하는 단일 웹 애플리케이션입니다.

---

## 1. 주요 기능 (Key Features)

### 1.1 멀티 윈도우 데스크톱 UX (`window-mgr.js`)
- **자유로운 창 제어:** 모든 탐색기·팝업 창의 드래그 이동(실시간 이동 / Win95 점선 프레임 이동 전환 지원), 최소화, 포커싱(`z-index` 자동 관리), 작업표시줄 탭 동기화 및 계단식 창 배열(`Cascade`) 제공.
- **데스크톱 테마 및 레트로 효과:** 바탕화면 3종(클래식 틸, 모눈종이, 벽돌), CRT 스캔라인 필터, 8비트 Web Audio 효과음 합성기, 스크린세이버 및 블루스크린(BSOD) 이스터에그 탑재.

### 1.2 Google Sheets 기반 감상 기록 CRUD 및 메타데이터 수집 (`archive-app.js`, `backend/`)
- **원클릭 메타데이터 검색:** 작품명, 아티스트, 또는 URL 입력만으로 도서·음악·영상 메타데이터(제목, 제작자, 장르, 표지 이미지, 원본 링크)를 자동 조회하여 입력 폼에 반영.
- **시트 실시간 동기화(CRUD):**
  - **조회·필터링:** 매체별 탭(전체/도서/음악/영상/기타), 최소 평점 필터, 키워드 실시간 검색 및 CSV 일괄 백업.
  - **등록·수정·삭제:** 동일 매체·동일 제목 중복 등록 자동 차단, 상세 탐색기 창 내 편집 모드 및 안전 삭제(2단계 인라인 확인) 지원.
- **퀵 메모장(`MEMOPAD.EXE`):** 아이디어나 짧은 감상 단상을 별도 `Notes` 시트에 즉시 저장 및 조회.

### 1.3 계정 없는 YouTube 백그라운드 주크박스 (`window-mgr.js`, `Code.gs`)
- 아카이브의 **음악** 카테고리에 등록된 트랙을 자동으로 불러와 재생목록을 구성합니다.
- 원본 링크가 YouTube/YouTube Music URL인 경우 즉시 `videoId`를 추출하고, 링크가 없는 곡은 저작자·제목을 기반으로 백엔드에서 일치 영상을 자동 매칭하여 **YouTube IFrame Player API**로 페이지 내 백그라운드 연속 재생(트랙 종료 시 다음 곡 자동 전환)을 수행합니다.

### 1.4 선택형 취향 데이터 시각화 (`visualizer.js`)
- **기본 대시보드:** 누적 기록 수, 평균 평점, 최다 감상 매체/장르 KPI 카드 및 Chart.js 기반 도넛·월별 막대 차트 제공.
- **온디맨드 고밀도 분석:** 사용자가 실행을 선택할 때만 한줄평과 장르에서 추출한 **키워드 워드클라우드** 및 매체·장르·작품 간 연결 관계를 탐색할 수 있는 **Canvas 물리 기반 인터랙티브 노드 맵**을 동적 생성.

### 1.5 내장 레트로 미니게임 (`GAMEPACK95.EXE`)
- **윈도우 클래식 카드놀이 (`SOL.EXE`):** 52장 표준 트럼프 카드 기반 클론다이크 솔리테어(더블클릭 완성 홈 자동 이동 지원).
- **스파이더 카드놀이 (`SPIDER.EXE`):** 104장(2벌) 카드, 10개 작업 열, 1무늬/2무늬 난이도 선택 및 5회 카드 배분 지원.
- **지뢰찾기 & 아카이브 미니게임:** 8×8 지뢰찾기, 내 아카이브 표지로 즐기는 12장 카드 짝맞추기, 작품 별점 하이로우 대결.

```text
my-archive-95/
├── index.html                  # 메인 데스크톱 셸(바탕화면 아이콘, 메뉴바, 작업표시줄, 창 컨테이너)
├── PRD.md                      # 제품 요구사항 정의서 및 아키텍처 명세
├── README.md                   # 프로젝트 안내 및 배포 가이드
├── css/

├── js/
│   ├── config.js               # 전역 상태, GAS 엔드포인트, 8비트 사운드 합성기, 부팅/BSOD/화면보호기

│   └── archive-app.js          # Google Sheets CRUD, 기본 통계 차트, 상세/연관추천, 퀵 메모장
└── backend/                    # Google Apps Script 프로젝트 파일
    ├── Code.gs                 # doGet / doPost 라우팅, Archive/Notes 시트 CRUD, YouTube 트랙 폴백 검색
    └── SearchService.gs        # 다중 외부 API 검색, OpenGraph 파싱, 관련도 내부 정렬 로직

##3. 설치 및 배포 방법 (Setup & Deployment)
###3.1 Google Apps Script 백엔드 설정
- 새 Google 스프레드시트를 생성하고 상단 메뉴에서 [확장 프로그램] → [Apps Script]를 엽니다.

- backend/Code.gs와 backend/SearchService.gs의 코드를 Apps Script 프로젝트에 각각 붙여넣고 저장합니다. (최초 실행 - 시 Archive 및 Notes 시트와 헤더가 자동 생성됩니다.)

- 우측 상단 [배포] → [새 배포]를 클릭하고 유형을 웹 앱(Web App)으로 선택합니다.

- 다음 사용자 권한으로 실행: 나(Me)

- 액세스 권한이 있는 사용자: 모든 사용자(Anyone)

- 발급된 웹 앱 URL(/exec)을 복사합니다.

###3.2 프론트엔드 연결 및 실행
- js/config.js 파일 상단의 GAS_WEB_APP_URL 상수에 발급받은 웹 앱 URL을 입력합니다.

- 별도의 빌드 과정 없이 index.html을 브라우저로 열거나 GitHub Pages, Vercel, Netlify 등 정적 호스팅에 업로드하여 즉시 사용할 수 있습니다.
